# Analytics Plan

Ask2Gift does not currently install analytics. This document outlines future privacy-conscious events that could be measured later.

## Suggested events

- quiz_started
- quiz_completed
- recommendations_displayed
- product_link_clicked
- favorite_added
- favorite_removed
- helpful_feedback_selected
- not_helpful_feedback_selected
- fallback_recommendations_used

## Privacy guidance

- Do not send personal information.
- Do not send full free-form messages.
- Do not log full quiz-answer payloads if simpler aggregate event data is enough.
- Prefer anonymous usage metrics that help improve recommendation quality and site usability.
